こんな人向け

意志の力だけでは続かない——だから、OS レベルでロックします。

  • アプリを選んでロック

    全部ブロックではなく、分散の原因だけを指定。 直近7日の使用時間を参考に、よく開くアプリから選べます。

  • 15分〜4時間

    短い集中から長時間の作業まで、プリセットから時間を選んで開始。 カウントダウンで残り時間がひと目でわかります。

  • 本当に使えない

    ロック中にブロック対象を開くと、「集中タイムです」の シールド画面が表示され、アプリは起動できません。

  • 解除は意図的に

    時間前の解除は有料（消耗型）。本当に必要なとき用に、 1週間に1回の無料緊急解除も用意しています。

3ステップで開始

  1. 1

    Screen Time を許可

    初回のみ、Apple の Screen Time API へのアクセスを許可します。

  2. 2

    アプリと時間を選ぶ

    ロックするアプリと、集中したい時間（例: 60分）を選びます。

  3. 3

    ロックを開始

    あとはタイマーが終わるまで集中。誘惑のアプリは開けません。
